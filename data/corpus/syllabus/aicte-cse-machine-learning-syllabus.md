# Machine Learning Syllabus (AICTE Model Curriculum, B.Tech CSE)

This is the Machine Learning syllabus from the AICTE Model Curriculum for the UG degree in Computer Science and Engineering (revised 2022), published by AICTE, the All India Council for Technical Education. It is a model syllabus that universities adapt. It is not LPU's own syllabus: LPU does not publish its course syllabi on its public website, so LPU's course code, credits and units may differ. In LPU's B.Tech CSE offerings, machine learning is covered in Artificial Intelligence Essentials (Year 2 Spring) and specialised tracks such as B.Tech AI and Machine Learning and Data Science with ML.

## Topics at a glance

**Q:** What topics are covered in the Machine Learning syllabus?
**A:** The AICTE Machine Learning syllabus covers four essential modules: an introduction to ML (features, linear transformations, classification vs regression, Bayes' rule, supervised and unsupervised learning), fundamentals of ML (PCA, k-nearest neighbours, linear regression, decision trees, overfitting and train/validation/test splits), selected algorithms (ensembles and random forests, linear SVM, k-means, logistic regression, Naive Bayes), and neural network learning (gradient descent, MLP, backpropagation, regularisation, deep learning and CNNs).

## Module 1: Introduction to ML (about 2 weeks)

- Motivation and role of machine learning in computer science and interdisciplinary problem-solving.
- Feature representation, linear transformations, matrix-vector operations, eigenvalues, eigenvectors and matrix rank.
- Problem formulations: classification and regression.
- Probability distributions, prior probabilities and Bayes' rule.
- Learning paradigms: primarily supervised and unsupervised learning, with an overview of other paradigms and limits of data-driven solutions.

## Module 2: Fundamentals of ML (about 3 weeks)

- Principal Component Analysis (PCA) and dimensionality reduction.
- Nearest neighbours and k-Nearest Neighbours (kNN), including hyperparameter $k$ and decision boundaries.
- Linear regression and decision tree classifiers.
- Generalization, overfitting (such as deep decision trees), and splitting data into training, validation and testing sets.

## Module 3: Selected algorithms (about 4 weeks)

- Ensemble methods and Random Forests (RF).
- Linear Support Vector Machines (SVM), support vectors and the geometric view of margin.
- K-means clustering and unsupervised discovery.
- Logistic regression (probabilistic view of margin) and Naive Bayes classifiers (such as text classification).
- Optimization, convergence, initialization and loss functions (mean squared error and cross-entropy).

## Module 4: Neural network learning (about 4 weeks)

- Loss functions, optimization, gradient descent and perceptron/delta learning.
- Multi-Layer Perceptrons (MLP) and the backpropagation algorithm for classification and regression.
- Regularisation and early stopping.
- Introduction to deep learning and Convolutional Neural Networks (CNNs) for tasks such as image classification.

## Desirable modules (optional)

- Key concepts from ML: kernels with SVM, Bayesian methods, generative methods, Hidden Markov Models (HMM), Expectation-Maximization (EM) and PAC learning.
- Deep learning architectures: popular CNN architectures, Recurrent Neural Networks (RNNs) for language models, Generative Adversarial Networks (GANs) and generative models.
- Training modern neural networks: advances in backpropagation, momentum, update rules, regularisation and adversarial learning.

## Textbooks and references

Textbooks: Introduction to Machine Learning (Jeeva Jose, Khanna); Mathematics for Machine Learning (Deisenroth, Faisal and Ong, Cambridge University Press, 2020); Machine Learning (Tom M. Mitchell, McGraw-Hill); Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (Aurélien Géron, 2nd edition, O'Reilly).

References: Deep Learning (Goodfellow, Bengio and Courville, MIT Press); Pattern Recognition and Machine Learning (Christopher M. Bishop, 2nd edition, Springer); The Elements of Statistical Learning (Hastie, Tibshirani and Friedman, 2nd edition, Springer); Machine Learning (Rajiv Chopra, Khanna).
