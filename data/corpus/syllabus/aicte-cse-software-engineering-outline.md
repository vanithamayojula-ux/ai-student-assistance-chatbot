# Software Engineering Course Outline (AICTE Model Curriculum, B.Tech CSE)

This is the Software Engineering course outline from the AICTE Model Curriculum for the UG degree in Computer Science and Engineering (revised 2022), published by AICTE, the All India Council for Technical Education. Unlike the core subjects, AICTE gives Software Engineering only as a short outline, without module-wise units, weekly hours or textbooks. It is not LPU's own syllabus: LPU does not publish its course syllabi on its public website. In LPU's published sample B.Tech CSE curriculum, Software Engineering is a Year 1, Spring term course.

## Topics at a glance

**Q:** What topics are covered in the Software Engineering course?
**A:** The AICTE Software Engineering course covers the iterative software development process, project planning, requirements including the user interface, architecture and design, coding with modern IDEs, testing, and integration and deployment, applied in a team software project.

## Purpose of the course

In AICTE's words, the course is "to explain the iterative software development process and different aspects of it (e.g. short cycles, agile approaches, test-driven-development, etc.), and to apply the concepts to a team project to develop software."

## Topics

- The iterative software development process.
- Basic project planning for such a process.
- Requirements, including the user interface.
- Architecture and design.
- Coding using modern IDEs.
- Testing.
- Integration and deployment.

## Learning outcomes of the Software Engineering specialization

1. Understand the role and importance of software engineering in developing industrial-strength software.
2. Work in a team to apply proper software engineering practices and build working software that solves users' problems.
3. Understand and apply testing, maintenance, open source software, model-based development and requirements engineering.

## Related half-courses in the same specialization

- Software Testing: unit testing and test frameworks, black-box and white-box test case design, non-functional testing, test automation and tools, and coverage and performance metrics.
- Open Source Software: how open source evolved, common open source practices and platforms, and a small project on a platform such as GitHub.
- Software Maintenance: the defect cycle and bug management, regression testing, change management, refactoring, software evolution and related metrics.
