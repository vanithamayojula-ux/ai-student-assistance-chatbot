3. Test A: automated tests (pytest)

Later the same day: twelve more documents appeared in data/corpus/ (modified 27 Nov, 10:14 to 10:15; not written during these tests): four AICTE syllabi (data structures, databases, discrete mathematics, machine learning) and eight LPU documents (libraries, sports and NCC, UMS and mentoring, convocation, holidays, education loans, grievance and ICC, student organisations). With them the corpus has 48 documents and 400 passages, and a re-run gave 24 passed, 1 failed: test_out_of_scope_question_is_declined. "Who won the cricket world cup?" now has confidence 0.46 (threshold 0.45) because a new sports document mentions cricket, so it is answered instead of declined. Everything else in this report, including the 25 passes below, was measured on the 36 documents that existed before.

Command: python -m pytest -v. Result on the 36 documents: 25 passed, 0 failed, 0 skipped in 4 minutes 55 seconds. Two tests are slow (about 100 seconds each) because uploading or deleting a document makes the program compute the vectors of every passage again, and this run shared the laptop with other jobs. One test (test_lpu_question_is_answered_from_lpu_documents_only) was added and one (test_answer_is_grounded_and_cited) was changed during this work.

5. Test C: the decline threshold

Uni Help declines when its confidence score is below a threshold. The threshold is chosen on the dev half of the 130 questions and reported on the test half, which plays no part in choosing it.

SettingAnswerable questions answeredOut-of-scope declinedBalanced accuracy
Before: threshold 0.58, dev half81.6%56.2%68.9%
Before: threshold 0.58, test half77.5%31.2%54.4%
Now: threshold 0.45, dev half (chosen on this)95.9%37.5%66.7%
Now: threshold 0.45, test half95.9%25.0%60.5%

The best threshold on dev moved from 0.58 to 0.45. At 0.45, Uni Help answers 96% of the answerable test questions (before: 78%) but declines only 25% of the out-of-scope ones (before: 31%). With 16 out-of-scope questions per half, each question moves that rate by 6 points, so treat it as a rough indication.

12. Open problems and limits of this testing

  • Declining out-of-scope questions is the weakest part: only 31.2% of the 32 out-of-scope questions in the 130-question set are declined, and 60% in the LPU set. Examples that were wrongly answered: the MBA fee at LPU (answered with the B.Tech fee) and the PhD stipend at LPU (answered with an intern stipend).
  • The threshold is a trade-off: lowering it from 0.58 to 0.45 answers more of the answerable questions (96% instead of 78% on the test half) but lets more out-of-scope ones through (declined 25% instead of 31% on the test half).
  • Wording matters: "How much do I pay to get my paper rechecked?" is answered with the wrong fee. Reworded and Hindi-English questions are still the weakest styles.
  • A question that names no university can be answered from either university's documents.
  • The 130 questions do not measure the LPU documents, and one label (Q075) is now out of date. The 32 LPU questions are few.
  • The LPU and training questions were written by the same AI assistant that wrote the documents. The LPU key facts were taken from the documents, so that test is easier than questions from real students. Real student questions were never collected.
  • The L01 fix was made after seeing the failure, so the LPU score of 27 of 27 is not a clean first-try result (the first run was 26 of 27). The question set was not otherwise changed.
  • The local model was tested on 24 November, before the LPU documents existed, and was never trained on them. Its smoke-test result is from 32 questions.
  • The website was checked by loading the pages and three screenshots, not by automated clicking. In the chat screenshot the answer had not appeared yet (the local model was still writing); answers were verified through the API and the tests instead.
  • Not tested: many users at once (apart from the rate-limit unit test), the Gemini and Claude modes against the real services (only against a simulated Gemini), PDF and Word uploads (only a text upload is tested), and the deployed Vercel and Render copy.
  • The 12 documents added later were not tested. The retrieval and answer scores, the LPU smoke test and the guides describe 36 documents; the 130 questions and the evaluation have not been re-run on 48. One automated test now fails (see section 3).
  • The project report (report/AI_Student_Assistance_Chatbot_Report.docx) still has the old numbers. It is rebuilt with report/build_report.py.
